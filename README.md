# ⚔️ Wings of Freedom

The Titans are here. The world needs saving. And somehow, you're the one with the grappling hooks.

Swing through Trost, strike Titan napes, and turn into the Attack Titan when things get messy. A small, fun Attack on Titan fan game you can play right in your browser.

## 🌍 Save the world

**[Play now →](https://erfanezk.github.io/aot/)**

Play on desktop or on your phone, with questionable amounts of courage.

On mobile, drag the **left stick** to sprint automatically. **Drag the world** to look around. Hold **Grapple** to fly; drag that same thumb to aim while grappling. Tap **Jump**, **Strike**, **Titan**, or **Supply** for the other actions. Use **Ⅱ** to pause. Both portrait and landscape work; landscape gives you more room.

Desktop controls:

- **WASD** — sprint · **Mouse** — look
- **Space** — jump · **Shift** — boost while grappling
- **E / Right click** — grapple
- **F / Left click** — attack
- **T** — unleash your inner Titan
- **R** — resupply · **Esc / P** — pause

Models and game assets are cached after your first visit, so you can spend more time saving humanity and less time downloading Titans.

## 🛠️ Run your own mission

```sh
npm install
npm run dev
```

`npm run build` builds the game. `npm run deploy` deploys the latest code pushed to `master` through GitHub Actions (requires GitHub authentication).
